## Изменение ui спедометра @Car.jsx

1. Белый фон
background: #fff;
border: 1px solid #333;

Из-за этого спидометр напоминает обычный div.

Лучше сделать:

темное стекло;
легкий blur;
внутреннюю тень;
отражение сверху.

Например:

background: linear-gradient(
    180deg,
    rgba(35,35,35,.95),
    rgba(10,10,10,.98)
);

border:1px solid rgba(255,255,255,.12);

box-shadow:
0 0 25px rgba(0,0,0,.6),
inset 0 2px 8px rgba(255,255,255,.08),
inset 0 -10px 20px rgba(0,0,0,.7);

Получится ощущение настоящего автомобильного стекла.

2. Стрелка

Сейчас

background:red;
width:3px;

Она выглядит как палка.

Лучше сделать длинную металлическую стрелку.

background:
linear-gradient(
90deg,
#d8d8d8,
#ffffff,
#bcbcbc
);

width:4px;

border-radius:4px;

box-shadow:

0 0 10px rgba(255,60,60,.6);

И добавить красный наконечник.

3. Центр стрелки

Сейчас

background:#333;

Лучше сделать металлическую шайбу.

background:
radial-gradient(
circle,
#ffffff 0%,
#d9d9d9 35%,
#555 70%,
#222 100%
);

box-shadow:

0 0 12px rgba(255,255,255,.15);

8. Контейнер

Сейчас

Это смотрится как Windows XP.

Лучше

rgba(18,18,18,.72);

border:1px solid rgba(255,255,255,.08);

0 12px 30px rgba(0,0,0,.55);

10. Цвет стрелки

11. Анимация

Сейчас

transition:.1s;

Лучше

transition:

transform .22s cubic-bezier(.2,.9,.1,1);

Стрелка станет двигаться плавно как в настоящей машине.

12. Канистра топлива

Я бы полностью переделал.

Не обычная иконка.

А вот такая

 ┌────────┐
 │███████ │
 │██████  │
 │████    │
 │██      │
 └────────┘

где:

жидкость плавно двигается;
стеклянный эффект;
сверху блик;
снизу тень;

при 10% красным;
при 5% появляется мягкая пульсация.
