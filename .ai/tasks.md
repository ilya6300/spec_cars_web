- [x] 8. [Высокий] Цветовая индикация скорости — белый / жёлтый / красный
  ### 📝 Описание
  Добавить цветовую индикацию скорости: до 80 км/ч — белый, 80-120 — жёлтый, 120+ — красный. Применить к цифрам шкалы и цифровой скорости.
  ### 🔧 Технические требования
  - Вычислить цвет на основе `displaySpeed`:
    - `<= 80`: `#ffffff`
    - `> 80 && <= 120`: `#ffb400`
    - `> 120`: `#ff3a3a`
  - Применить цвет к:
    - `.speedometer-digital-display` и дочерним элементам
    - `.gauge-label-text` (каждой цифре шкалы)
    - `.gauge-tick-line` (делениям)
  - Использовать computed-свойство или inline-стиль с условной логикой
  ### 🧪 Критерии приёмки
  1. При скорости <= 80 — все элементы белые.
  2. При скорости 81-120 — все элементы жёлтые.
  3. При скорости > 120 — все элементы красные.
  4. Плавный переход цвета при пересечении порогов.
  ### ⚠️ Edge Cases
  - Граница 80 и 120 — точная логика: `<= 80` белый, `> 80 && <= 120` жёлтый, `> 120` красный

- [x] 9. [Средний] Редизайн канистры топлива — стеклянный эффект
  ### 📝 Описание
  Полностью переделать компонент Bensin.jsx: стеклянная канистра с плавным заполнением, бликом, тенью. Цвет меняется при низком уровне топлива. Пульсация при 5%.
  ### 🔧 Технические требования
  - Новая структура канистры:
    - Контейнер `canister` — прямоугольник со скруглёнными углами, стеклянный эффект
    - Внутренний `fuel-fill` — заполнение градиентом снизу вверх
    - `glare` — блик сверху (полупрозрачный белый градиент)
    - `shadow` — тень снизу
  - Цвет топлива:
    - `> 20%`: зелёный/голубой `#4ade80`
    - `10-20%`: янтарный `#f59e0b`
    - `5-10%`: красный `#ef4444`
    - `< 5%`: красный + пульсация (`@keyframes pulse`)
  - Анимация заполнения: `transition: height 0.3s ease`
  - Пульсация при < 5%: `animation: pulse 1s infinite`
  - Обновить JSX и CSS-классы
  ### 🧪 Критерии приёмки
  1. Канистра имеет стеклянный вид с бликом и тенью.
  2. Уровень топлива заполняется плавно.
  3. Цвет меняется: зелёный → янтарный → красный.
  4. При < 5% — пульсация красного цвета.
  ### ⚠️ Edge Cases
  - `fuel = 0` — канистра полностью пустая
  - `fuel = maxFuel` — канистра полностью заполнена
