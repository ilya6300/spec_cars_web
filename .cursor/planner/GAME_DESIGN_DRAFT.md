## A0 — Система пешеходов (**в PLAN.md**)

### Спавн

- Каждый `humanN` — **свой рандомный интервал** (`minDistance` / `maxDistance` / `initialSpawnDistance`).
- **Отклонено:** фиксированная плотность «1 на 200–400 м».
- Люди **могут спавниться рядом** (группы). Cap на экране — чтобы улица не была забита.

### Профиль инстанса

`sidewalkSlot` (Y), `driftSpeedX`, `driftSpeedY` (редко), `groupId`, `pairRole`, `reactionToAggr` (`flee` | `watch`).

### Движение

- Разная скорость по X у каждого.
- Смещение по Y — **реже и слабее**, чем по X.

### Реакция на aggr

- **70%** — `flee` (~9 м радиус, ~5 м макс. отход).
- **30%** — `watch` (стоят, смотрят).

## A1 — Idle-анимация пешеходов

**Суть:** мирные пешеходы `human1–16` слегка «дышат» на месте — убирает ощущение манекенов.

| Параметр | Значение |
|----------|----------|
| Объекты | Только `human1`…`human16` (regex `^human\d+$`) |
| Движение | `translateY` 2–4 px, период 1.2–2.5 с |
| Фаза | Случайная задержка от `uid` (каждый со своим ритмом) |
| Действие игрока | Нет |
| Реализация | CSS-класс на `.game-object` в `Maps.jsx` + `@keyframes` в `src/style/` |
| Исключения | `human_aggr*`, quest crossing, chase (peaceful humans уже skip) |

**Не менять:** z-index, коллизии с машиной игрока. `worldX` / Y — через профиль A0/A2.

## A2 — Drift пешеходов (в основном X, редко Y)

**Суть:** у каждого human свой `driftSpeedX`; смещение по Y (`sidewalkSlot` / `driftSpeedY`) — **реже и слабее**.

| Параметр | Значение |
|----------|----------|
| X | `worldX += driftSpeedX * deltaTime` |
| Y | редкий дрейф между слотами тротуара, не постоянный |
| Follower | копирует `driftSpeedX` лидера группы |
| Исключения | `watch` у aggr — drift X = 0; chase — peaceful skip |

## C2 — «Заглохла у обочины»

### Фантазия

На обочине стоит гражданская машина — перегрелась / заглохла. Игрок вызывает эвакуатор по рации. Как квест парковки, но **помощь**, не штраф.

### Как игрок понимает, что машина сломалась

| Сигнал | Описание |
|--------|----------|
| **Позиция** | Стоит **у обочины** (не на парковке, не в потоке) |
| **Скорость** | `speed = 0`, привязана к `worldX` (environment object) |
| **Аварийка** | CSS-мигание hazard lights (медленнее сирены, оранжевый) |
| **Пар** | **Белый пар** из-под капота спереди — CSS/SVG overlay, `opacity` + `translateY`. **Без новых PNG-спрайтов** |
| **Капот** | **Закрыт** — отдельный спрайт открытого капота **не делаем** |

Визуально: **стоит + мигает + парит** = сломалась, нужна помощь.

### Геймплей (одно действие, ≤15 с)

```
1. Спавн объекта `roadside_breakdown` с civilian CarModel
2. Игрок подъезжает, тап по машине
3. playRatioSound() — как парковка
4. Ratio: «Диспетчер, нужен эвакуатор.» — ТОТ ЖЕ текст, что при неправильной парковке
5. spawn_delay → эвакуатор (фазы: approaching → loading → loaded → departing)
6. finalize → addHelp('roadsideHelp')
```

**Сообщение Ratio — зафиксировано:** `Диспетчер, нужен эвакуатор.` (идентично парковке, `Game.jsx`).

### Переиспользование кода парковки

| Компонент | Как использовать |
|-----------|------------------|
| `parkingEvacuation` | Расширить или общий `evacuation` state с теми же фазами |
| `Evacuator` | Без изменений |
| `Ratio` | **Тот же текст** при `spawn_delay` |
| `playRatioSound` | При клике по машине |
| Тайминги эвакуатора | Из `parkingZoneConstants` |

**Отличие от парковки:** нет `parking_zone`; одна машина на обочине; клик по `CarModel`.

### Триггер спавна

| Параметр | Предложение |
|----------|-------------|
| Тип | `roadside_breakdown` в `objects.jsx` |
| Интервал | как `gas_station`: **175–400 м** (3 500–8 000 world px) или реже |
| Режимы | `free` + `timed`; не в `chase` |
| Взаимоисключение | Как у остальных квестов + `!isParkingFineActive()` + `!isRoadsideHelpActive()` |

### Очки

**`roadsideHelp`**: +2 free / +3 timed — эмоция «помог на дороге».

### Assets

| Что | Решение |
|-----|---------|
| Пар | CSS/SVG overlay — **без новых спрайтов** |
| Аварийка | CSS на `.roadside-breakdown-car` |
| Машина | Случайный `Cars.otherCars` (существующий `CarModel`) |
| Открытый капот | **Не делаем** |

### E2E

- `data-type="roadside-breakdown-car"`
- `data-type="roadside-breakdown-steam"`

## Идеи оживления мира (на будущее, не в PLAN)

Продуктовое ядро: помочь, поймать, защитить — без тревоги и наказания за пропуск.

### Ambient — без действия игрока (только CSS / лёгкая логика)

| ID | Идея | Реализация |
|----|------|------------|
| **L1** | Деревья качаются на ветру | `rotate` 1–2° на `tree*` |
| **L2** | Окна домов ночью | Тёплый `box-shadow` на случайных `building` при `isNight` |
| **L3** | Птицы от дерева | 3 точки вверх + fade, раз в N спавнов |
| **L4** | Фонари вечером | Мягкий glow у `traffic_light` / столбов |
| **L5** | Листья на дороге | Редкий мелкий спрайт, дрейфует медленнее мира |
| **L6** | Пешеходы вдвоём | Два human рядом с одним `driftSpeed` (группа) |

### Микро-квесты — тот же паттерн, что C2

**Визуальный сигнал → тап → «Диспетчер, нужен эвакуатор.» → эвакуатор → молодец**

| ID | Название | Сигнал (без новых спрайтов) |
|----|----------|----------------------------|
| **C3** | Спустило колесо | Наклон CSS `rotate`, аварийка одной стороны |
| **C4** | Пустой бак | human машет рядом с машиной у обочины |
| **C5** | Застряла | Колёса крутятся (CSS spin на wheel), машина не едет |

### Микро-квесты — другие службы

| ID | Название | Сигнал | Ratio / действие |
|----|----------|--------|------------------|
| **C6** | ДТП без пострадавших | 2 машины, hazard на обеих | Тап → «Оформляю происшествие» → короткая модалка |
