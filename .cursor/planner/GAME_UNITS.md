# Единицы расстояния spec_cars_web

> **Обязательно для всех агентов:** Orchestrator, Planner, Architect, Developer, Reviewer, UI/UX Designer, Game Art Director, Game Design Director, Technical Documentation Writer.
>
> Читать перед планированием спавна, баланса, квестов, туториала и **перед любым упоминанием дистанций в диалоге с пользователем**.

---

## 1. Главное правило

В коде дистанции хранятся в **world px** (`offsetX`, `worldX`, `minDistance`, `maxDistance`, `initialSpawnDistance`).

**Игровые метры** (то, что видит игрок в HUD и что нужно писать в PLAN/SPEC/диалоге):

```
gameMeters = worldPx / distanceMetersFactor
```

`distanceMetersFactor = 20` — `src/state/state_app.jsx`.

**Километры в игре:**

```
gameKm = worldPx / (distanceMetersFactor * 1000) = worldPx / 20000
```

**Обратная конвертация (из метров в код):**

```
worldPx = gameMeters * 20
```

### Запрещено

- Писать «500 м» или «2 км», имея в виду число из `minDistance` / `initialSpawnDistance` **без деления на 20**.
- Называть world px «метрами» или «километрами» напрямую.
- Планировать баланс «на глаз» без таблицы конвертации.

### Обязательно

В PLAN, SPEC, GAME_DESIGN_DRAFT, диалоге с пользователем указывать **игровые метры** (и при необходимости world px в скобках для разработчика):

> «Интервал спавна пешеходов **200–400 м** (4000–8000 world px)»

## 2. Где в коде

| Что | Файл | Единица в коде |
|-----|------|----------------|
| Фактор конвертации | `src/state/state_app.jsx` | `distanceMetersFactor = 20` |
| Пройденный путь (HUD) | `carStore.distanceMeters` | **уже игровые метры** |
| Накопление пути | `carStore.updatePhysics` | `(realSpeed * deltaTime) / distanceMetersFactor` |
| Км на экране / в UI | `Game.jsx` | `offsetX / distanceMetersFactor / 1000` |
| Спавн объектов | `objects.jsx`, `subobject.jsx`, `mapStore.spawnEnvironmentObjects` | **world px** |
| Смещение мира | `mapStore.offsetX` | **world px** |

## 5. Пешеходы A0 (зафиксировано в PLAN.md)

Спавн: **рандомный интервал у каждого типа**; группы могут появляться рядом; cap на экране (не вся улица в людях). **Не** использовать фиксированную плотность «1 на 200–400 м».

| Параметр | Игровые метры | world px |
|----------|---------------|----------|
| Радиус реакции на aggr | **~9 м** | 180 |
| Макс. смещение при побеге (70% flee) | **~5 м** | 100 |
| Смещение follower в группе | **~3–6 м** | 60–120 |

## 6. Чеклист агента

Перед тем как указать дистанцию в SPEC, PLAN или ответе пользователю:

- [ ] Число из кода? → разделить на **20** для метров.
- [ ] Нужны км? → разделить world px на **20 000**.
- [ ] Задаёте новый баланс? → сначала метры для геймдизайна, потом `× 20` для кода.
- [ ] В диалоге с пользователем — **метры/км**, не сырые world px (px — только в скобках для Developer).
