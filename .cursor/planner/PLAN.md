## В работу

### 1. A0 — Система мирных пешеходов

**Проблема:** все `human1–16` на одной высоте (`bottom: 65%`), пачки в начале, нет реакции на `human_aggr*`.

#### Спавн

- У каждого типа `humanN` — **свой случайный интервал** (`minDistance` / `maxDistance` / `initialSpawnDistance` с разбросом).
- Люди **могут появляться рядом** (в т.ч. группы).
- **Cap на экране** — улица не должна быть полностью забита пешеходами (число — в SPEC).
- **Не делаем:** единый диспетчер с плотностью «1 на 200–400 м».

#### Профиль на инстансе (`activeObjects[].pedestrian`)

| Поле | Назначение |
|------|------------|
| `sidewalkSlot` | Y на тротуаре (разная высота, несколько уровней `bottom`) |
| `driftSpeedX` | скорость вдоль дороги (world px/s), у каждого свой |
| `driftSpeedY` | редкое смещение по Y — **слабее и реже**, чем X |
| `groupId` | общий id группы |
| `pairRole` | `leader` \| `follower` \| null |
| `reactionToAggr` | `flee` \| `watch` — назначается при спавне |
| `fleeRadius`, `fleeSpeed`, `fleeMaxDistance` | побег от aggr |
| `spawnWorldX`, `spawnSidewalkSlot` | точка для клампа при flee |

#### Группы

- 2+ human с одним `groupId`.
- `leader` задаёт `driftSpeedX`; `follower` держит смещение **~3–6 м** (60–120 world px) по X.
- Группа = одно спавн-событие для cap.

#### Реакция на `human_aggr*` (в радиусе **~9 м** / 180 world px)

| Доля | Поведение |
|------|-----------|
| **70%** | `flee` — отбегают в стороны от aggr (по X, макс. **~5 м** / 100 world px) |
| **30%** | `watch` — стоят и смотрят, без побега |

Только на экране; не на проезжую часть; сброс после ухода aggr.

### 2. A1 — Idle-анимация пешеходов

- Мирные `human1–16`: лёгкое покачивание на месте (CSS `translateY` 2–4 px).
- Случайная фаза от `uid`.
- Без изменения логики квестов; исключения: `human_aggr*`, quest crossing, chase.

---

### 3. A2 — Движение по тротуару

- Основное движение: **X** (`worldX += driftSpeedX * deltaTime`).
- **Y** — редкий дрейф между слотами тротуара, не постоянный.
- У `watch` при aggr рядом: `driftSpeedX = 0`.
- Follower копирует скорость лидера группы.
