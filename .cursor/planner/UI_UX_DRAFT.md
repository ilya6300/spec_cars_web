## Сессия: Аудит HUD и controls — 2026-08-05

### Краткий анализ текущего UI

**Что уже хорошо:**
- Панель управления справа внизу (`gearbox.css`) — современный «стеклянный» стиль: blur, скругления, неоновая активная передача, адекватные touch targets (42–65 px).
- Педаль газа с 3D-наклоном при нажатии — понятный тактильный отклик для ребёнка.
- Адаптивность controls в `media.css` (landscape ≤900 px) — компактная панель, уменьшенные кнопки.
- Help badges и звёзды — простая система прогресса, emoji понятны детям.

**Что слабо / конфликтует:**
- **Два визуальных языка:** HUD сверху (канистра, спидометр, текст) выглядит как ранний прототип (плоский CSS, inline-стили в `Car.jsx`); controls снизу — polished dark glass. Игра воспринимается «склеенной из двух эпох».
- **Дублирование скорости:** аналоговый полукруг + цифра внутри + строка «Скорость: X км/ч» в `text-stats` — три источника одной информации; взгляд рассеивается.
- **Читаемость HUD на фоне игры:** `header_interface` без подложки; чёрный/серый текст и белый спидометр теряются на яркой траве и дороге.
- **Inline `<style>` в `Car.jsx` (~110 строк):** спидометр не вынесен в CSS; сложно поддерживать единый стиль с controls.
- **Конфликт CSS controllers:** `control.css` и `gearbox.css` оба задают `.controllers_container`, `.gas_pedal`, `.ignition-key` — разные значения; побеждает порядок импорта, не дизайн-система.
- **Help badges:** emoji 🚓👮🚶 на полупрозрачных белых pill — не совпадает с cartoon outline стилем игровых спрайтов.
- **Туториал:** палец `tutorial_finger_pointer.png` — непрозрачный фон и ~900 px исходник при отображении 60×60 px (`control.css`) — визуальный артефакт и профессиональный брак ассета.

---

### Проблемы (по приоритету)

1. **P0 — Визуальная целостность:** HUD и controls не из одной дизайн-системы.
2. **P0 — Читаемость HUD:** нет контрастной подложки; текст и gauge плохо видны на игровом фоне.
3. **P1 — Информационный шум:** скорость показана трижды.
4. **P1 — Технический долг UI:** inline styles в `Car.jsx`, дубли CSS в `control.css` / `gearbox.css`.
5. **P2 — Help badges:** emoji вместо согласованных иконок в стиле игры.
6. **P2 — Композиция:** HUD занимает верхнюю полосу без группировки; элементы «разбросаны» по горизонтали.

### Предложения улучшений

#### Предложение 1: Единая HUD-панель «Приборная панель» (S)

- **Что меняется:** объединить канистру, спидометр, дистанцию и badges в **одну компактную карточку** top-left — тот же glass/blur стиль, что у `controllers_container` (rgba фон, blur, border-radius 16px, лёгкая тень).
- **Почему лучше:** один визуальный блок; читаемость на любом фоне; соответствие controls; меньше «шума» на экране.
- **Приоритет:** S
- **Затронутые файлы:** `Car.jsx`, `interface.css`, новый `hud.css` или секция в `interface.css`
- **Адаптивность:** на landscape mobile — уменьшить padding, спидометр 80×40 px, скрыть дублирующий текст скорости.

| Параметр | Оценка |
|---|---|
| Понятность | ⭐⭐⭐⭐⭐ |
| Красота | ⭐⭐⭐⭐⭐ |
| Удобство детям 3+ | ⭐⭐⭐⭐⭐ |
| Простота реализации | ⭐⭐⭐⭐ |

---

#### Предложение 2: Убрать дублирование скорости (S)

- **Что меняется:** оставить **один** primary индикатор — аналоговый полукруг с цифрой внутри (как сейчас в gauge). Убрать строку «Скорость: X км/ч» из `text-stats`. Опционально: оставить только «Пройдено: X км» + badges под спидометром.
- **Почему лучше:** ребёнок видит скорость за 1 секунду; меньше текста — проще для 3+.
- **Приоритет:** S
- **Затронутые файлы:** `Car.jsx`
- **Адаптивность:** без изменений layout.

---

#### Предложение 3: Консолидация CSS controls (A)

- **Что меняется:** один источник правды — `gearbox.css` (+ `media.css`). Удалить дубли из `control.css` (оставить только tutorial-overlay, arrest button и прочее не-controls).
- **Почему лучше:** предсказуемый UI; проще менять стиль панели целиком.
- **Приоритет:** A
- **Затронутые файлы:** `control.css`, `gearbox.css`, порядок импортов в `Game.jsx` / `Controllers.jsx`

---

#### Предложение 4: Спидометр — вынести из inline в CSS-компонент (A)

- **Что меняется:** перенести стили спидометра из `<style>` в `Car.jsx` в `interface.css` или `Speedometer.jsx`; единая палитра (#fff gauge, accent #00c6ff для active states как у gear-btn).
- **Почему лучше:** поддерживаемость; можно анимировать стрелку и подсветку критической скорости (как `SpeedDisplay.critical`).
- **Приоритет:** A
- **Затронутые файлы:** `Car.jsx`, `interface.css`

---

#### Предложение 5: Help badges — иконки в стиле игры (B)

- **Что меняется:** заменить emoji на маленькие PNG/SVG иконки (64 px, transparent) в cartoon outline — машина, полицейский, пешеход; счётчик крупнее (min 16 px bold).
- **Почему лучше:** визуальная целостность с `src/assets/`; профессиональный вид.
- **Приоритет:** B (нужен Art Director для ассетов)
- **Затронутые файлы:** `HelpBadges.jsx`, `interface.css`, `src/assets/ui/`

---

#### Предложение 6: Канистра топлива — дружелюбнее и заметнее (B)

- **Что меняется:** увеличить до 52×68 px; добавить иконку капли/бензина; при <5% — пульсация + иконка «!» (не только blink border); цвет заливки — более насыщенный зелёный→жёлтый→красный gradient.
- **Почему лучше:** топливо — критичный ресурс; ребёнок должен заметить без чтения цифры.
- **Приоритет:** B
- **Затронутые файлы:** `Bensin.jsx`, `interface.css`

---

#### Предложение 7: Микроанимации обратной связи (B)

- **Что меняется:** при смене передачи — короткий scale pulse на active gear; при toggle ignition — flash зелёный/серый ring; при +1 help badge — bounce счётчика 300 ms.
- **Почему лучше:** положительный отклик без отвлечения от дороги (короткие анимации).
- **Приоритет:** B
- **Затронутые файлы:** `gearbox.css`, `interface.css`, опционально MobX reaction в store (только CSS preferred)

---

#### Предложение 8: Цветовая система состояний (B)

- **Что меняется:** документировать и применить единую палитру:
  - 🟢 OK / активно: `#00c6ff` (как active gear)
  - 🟡 внимание: `#ff9900` (neutral gear, low fuel)
  - 🔴 опасность: `#ff0055` (critical speed, empty fuel)
- **Почему лучше:** ребёнок учится читать UI по цвету; consistency с gearbox.
- **Приоритет:** B

### Чеклист приёмки (для будущей задачи ui-ux)

- [ ] HUD читается на ярком фоне травы/дороги без напряжения глаз
- [ ] Скорость понятна за 1 секунду (один primary индикатор)
- [ ] HUD и controls визуально из одной «семьи» (glass / radius / palette)
- [ ] Touch targets ≥ 48 px на mobile landscape
- [ ] Нет inline `<style>` блоков в компонентах HUD
- [ ] `prefers-reduced-motion` учтён для анимаций
